# 일일 재고 업데이트

사용자가 새 엑셀을 업로드하고 업데이트를 요청하면 원본은 공개 폴더에 복사하지 않고 아래 방식으로 교체합니다. 실시간 시스템 연결이 아닌, 재고표 기준일의 스냅샷입니다. 가격·할인율은 별도 근거가 있어야 변경합니다.

```sh
python3 scripts/import-stock.py /absolute/path/to/inventory.xlsx --as-of YYYY-MM-DD
python3 scripts/check-stock-import.py
node scripts/check-stock.cjs
sh scripts/check.sh
```

- allocation 시트는 전국·위탁·전시·배정 자료를 함께 담고 있으므로 시트 전체를 제외하지 않습니다. 배정재고 구분, 계약 확정·가계약, 판매 제한을 제외하고 미배정/판매 가능/입고 물량이면서 출고 가능일이 기준일 이하인 차량을 수집합니다. 예정·선적·생산 중, 출고일 불명은 즉시 출고로 표시하지 않습니다.
- 두 번째 시트는 판매여부가 빈칸이고 출고 가능일이 도래한 차량만 사용합니다. 판매완료·데모카완료는 제외합니다. 전국 표에 대응 차량이 있으면 배정재고·계약·판매제한 여부를 다시 확인합니다. 전시장 운영을 위한 위탁·전시 배정은 소비자 계약과 구분하며, 해당 구분은 공개하지 않습니다.
- 커미션 번호는 메모리 안에서만 중복 제거와 대조에 사용합니다. 공개 결과에는 모델명·연식·외장·내장·조합별 대수와 숫자형 화면 효과(accent)만 허용합니다. VIN, 메모, 위치, 고객 정보, 원본 행, 재고 구분은 내보내지 않습니다.
- 색상은 원본 한글명, 영문명 번역, 기존 모델 색상 사전 순으로 대조합니다. 불명확한 코드는 추측하지 않고 `색상 상담 확인`으로 표시합니다. 코드 대조가 실패한 항목은 실행 결과에 나오므로 운영자가 확인합니다.
- 같은 연식·동일 모델명의 알려진 별칭만 연결합니다. 140주년/RoF/마누팍투어·프리미엄·다른 연식에 재고를 공유하지 않습니다. 가격 목록에 없는 모델도 가격 페이지의 전체 출고 가능 목록에서 확인할 수 있습니다.
- 새 재고가 확인되면 기존 soldout 규칙보다 우선합니다. 표에서 사라졌다는 이유만으로 판매 소진으로 단정하지 않고 상담 확인으로 안내합니다.
- 데이터 파일은 한 번에 교체하고 브라우저가 재검증하도록 `_headers`에 no-cache를 적용합니다. 검증 후 승인된 기존 배포 경로로 반영하고 운영 자산의 기준일을 확인합니다.

## 간결한 색상표와 운영자 식별 효과 (2026-11-02)
- 검색은 NFKC 정규화·소문자·공백 제거 후 비교. GLB250 / GLB 250 / 전각 입력은 같은 결과.
- 가격·견적·비교의 모든 조합은 실제 table의 한 줄에 외장/실내/상담을 나란히 표시. 긴 소재명은 작은 설명에서 생략하고 원문은 title과 상담 내용에 유지. 표 헤더 고정, 개별 표 270px(모바일 280px), 전체 검색표 440px(모바일 400px) 안에서 스크롤. 페이지는 조합 수에 비례해 늘어나지 않음.
- 공개 데이터에 재고 구분 문자열이나 비고/메모 원문을 내보내지 않음. 숫자형 accent에만 다음 비트를 합성하고 CSS 효과로 표시. 로그인 보안 기능이 아니며 공개 코드에서 접근 가능한 시각적 표식.
- 1: 위탁 포함 — 행 왼쪽 첫 번째 파란색 선.
- 2: 전시 포함 — 행 왼쪽 두 번째 황금색 선.
- 4: Hot Car 포함 — 행 왼쪽 세 번째 빨간색 선.
- 8: 전시차 추가 1% 대상 포함 — 행 왼쪽 네 번째 노란색 선.
- Hot Car/추가1%는 보조 시트 B 비고의 명시적 표기만 판별. O 메모는 읽어 표시에 쓰지 않음. 판매가능 필터를 통과한 차량만 반영. 전국 표에 이미 존재하는 차량은 대수를 중복 가산하지 않고 효과 비트만 합침. 위탁/전시 카테고리는 C 및 전국 표 B/AG로 판별.
- 같은 모델·연식·내외장 조합에 여러 재고가 합쳐질 수 있으므로 효과는 해당 대상 재고가 포함됐다는 의미. 전체 대수가 같은 자격인 것은 아님. 여러 효과가 동시에 적용될 수 있음. 추가 할인은 표시만 하며 견적 할인율을 자동 가산하지 않음.

- 2026-11-02 후속 수정: 모든 효과는 행 왼쪽 2px 색상선으로만 통일. 네 가지 조건이 겹치면 고정 순서의 선들이 나란히 나타남. 글자색·색상 원 테두리·예약 밑줄 변화는 제거. 데이터 비트와 선정 기준은 동일.

- 개별 재고 카드는 같은 모델의 MY26/MY27 재고를 한 개의 높이 제한 표에 함께 표시하고 연식별 헤더·조합 수·빈 연식을 명시. 실제 stock.matches는 선택 연식만 판단하므로 다른 연식 재고로 판매상태를 바꾸지 않음. 에디션·엔진·차체는 기존 정확한 모델 연결만 유지. 상담 링크는 클릭한 실제 재고의 연식 사용, 가격·할인 연식 차이 안내.
