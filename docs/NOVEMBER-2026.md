# 2026년 11월 적용 조건

사용자 제공 `11월 조건.jpeg`, `11월 조건 2.jpeg`를 직접 대조. 이미지 머리글은 2026년 10월이나, 사용자가 이 채팅에서 ‘26년식 조건과 27년식 신규 적용 조건이 합쳐져 있으며 11월 기준으로 판단하고 진행’하도록 명시 확인. 확인일 2026-11-02. 원본 이미지는 공개 자산에 복사하지 않음.

- 원본 가격 목록 october-2026.js 및 OCTOBER_2026 식별자는 호환성을 위해 유지. november-2026.js가 그 뒤에 실행되어 근거 있는 모델의 할인만 덮어씀. 가격표 기준일은 2026-10-27 유지, 확인된 프로모션 날짜는 2026-11-02.
- 27년식 E200 Exclusive 현금14+MBM4, AMG Line14+3, E3008+4 유지/재확인. 27년식 GLC300 SUV7+1, 쿠페7+1 반영. 전기 GLC 및 다른 엔진에는 적용하지 않음.
- MBF 운용리스 추가는 MBM 추가와 합산. MBMK 장기렌탈은 해당 MBM+MBF+3%로 분리. 표의 26년식 S450SWB 7+4+2+3=16%, 마이바흐S580/680 9+2+3=14%와 검산.
- 27년식 GLC300 쿠페의 장기렌탈은 별도 줄이므로 MBM1% 제외, 7+3=10%. SUV는7+1+3=11%. 장기렌탈/운용리스 선택지를 분리하고 상담 파라미터·선택 기억·측정 enum에도 추가.
- 원본에 기재된 MY27 AMG GLS63 기본할인1% 신규 행 추가. 27년식 가격은 자료에 없어 null로 유지하고 상담 확인. 26년식 가격을 복사하지 않음.
- 재구매/트레이드인 등 상세율과 월납 지원·무이자 기간/선수금·바우처 금액은 두 요약표만으로 새 숫자를 만들지 않음. 기존 별도 자료와 구분, 11월 적용 여부 상담 안내. 추가1% 전시차 표시와 결제 조건 자동 중복 없음.
- 첨부표 밖 모델은 기존 자료를 지우거나 모든 차종에 새 조건을 확장하지 않음. ‘직전 확인 조건, 11월 상담 확인’ 명시. 기존 가격/기본할인/금융추가가 보존되는지 회귀 검사.
- 렌탈 페이지는 새 MBMK3%와 예외/총할인을 안내하고, 기존 롯데/SK·법인 조건을 직전 자료로 구분.

검증: scripts/check-november.cjs가 원본 기반 주요 결제별 총할인·만원절사·전기차 격리·미기재 모델/차량가 보존·장기렌탈 미확인 상태를 검사. scripts/check-comparison.cjs는 11월 overlay도 읽어 신규154트림 전체 비교를 검증.
