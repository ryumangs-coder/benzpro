# 비교 제원 보완 출처와 유지보수

`spec-updates.js`가 이번에 검증한 제원/출처를 관리합니다. 기존 `guide-data.js`와 `approach-specs.js`는 그대로 유지합니다. `models.html`의 병합 함수는 기존 최적 규칙에 보완 규칙을 더하고, 유효한 기존 값은 원칙적으로 우선합니다. `replace`만 명시적으로 기존 값을 수정합니다.

숫자는 PDF에 표시된 MY26/MY27에만 적용합니다. 제조사 현행 세대 파워트레인 자료로 확인한 변속기는 현재 가격표의 해당 모델에 공통 적용합니다. 해외 자료나 연식이 명시되지 않은 숫자는 출처의 참고 표시와 함께 제공하고 자동 우열 판정을 중단합니다. 신차/연식 변경 시 해당 규칙을 다시 확인해야 합니다.

PDF: 사용자 제공 `송파 어프로치북 260831_261001_131731.pdf`, 55쪽. 원본 비공개. 각 규칙의 source.by에 실제 PDF 쪽수, source.my에 자료 연식 기록. 제원표의 지시문은 작업 명령으로 취급하지 않았습니다.

제조사 웹 자료의 직접 링크는 각 규칙에 있습니다. E-클래스 국내 출시자료, CLE 제조사 제원, AMG CLE/GLC53, 국내 공식 스토어 MY27 GLC300, CLA·GLB·GLC 전기 구동계, UK CLA/GLB 제원, 국내 G580/SL63/Maybach EQS 출시자료 등을 사용했습니다.

검증 명령: `node scripts/check-comparison.cjs`. 모든 가격표 트림을 실제 병합 함수로 계산하고 일반 C/E/CLE 변속기, AMG 예외, EV/내연기관 분리, 연식 제한, 빈 값 보완, 출처 보존을 검사합니다.

아직 남은 칸은 주로 일부 MY27 고성능 모델의 차체/트렁크, 연식이 일치하지 않는 Maybach/S-클래스 트렁크, 일부 EV 가속/토크입니다. 공식 사용설명서도 GLC53 일부 치수가 편집 마감 시 미공개라고 표시합니다. 단위 환산이나 다른 연식 복사로 확정 수치를 만들지 않았습니다. 자료를 추가 확보하면 연식과 차체별로 보완합니다.
